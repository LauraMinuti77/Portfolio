# 💻 Portfólio Pessoal

Portfólio desenvolvido para apresentar meus conhecimentos, projetos, habilidades e formação na área de tecnologia.

O site reúne informações sobre minha trajetória como estudante de Ciência da Computação, além de projetos desenvolvidos durante meus estudos e cursos complementares.

## 👩‍💻 Sobre o projeto

Este portfólio foi criado com o objetivo de reunir meus principais projetos e facilitar a apresentação do meu trabalho para oportunidades de estágio na área de tecnologia.

O desenvolvimento contou com o auxílio de ferramentas de Inteligência Artificial na criação e melhoria de partes do código, que foram adaptadas e personalizadas de acordo com minhas preferências e conhecimentos.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* Flexbox
* Design responsivo

## ✨ Funcionalidades

* Menu de navegação entre as seções
* Apresentação pessoal
* Seção de habilidades
* Exibição dos principais projetos
* Cursos e certificações
* Links para GitHub, LinkedIn e contato
* Layout responsivo para diferentes tamanhos de tela
* Animações e efeitos visuais

## 📂 Projetos apresentados

O portfólio atualmente apresenta projetos como:

* 📊 Dashboard de Vendas — Power BI e Power Query
* ⚽ Quiz de Futebol — HTML, CSS e JavaScript
* 🔐 Gerador de Senhas — Python
* 🧮 Calculadora — Python e CustomTkinter

## 🎯 Objetivo

Continuar desenvolvendo meus conhecimentos por meio de projetos práticos e utilizar este portfólio para acompanhar minha evolução durante minha formação em Ciência da Computação.
